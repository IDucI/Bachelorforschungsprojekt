# CROSS on Embedded Systems – Implementation & Side-Channel Analysis

## Overview

This project focuses on the implementation and analysis of selected components of the post-quantum signature scheme CROSS on an embedded platform.

CROSS is a code-based digital signature scheme submitted to the NIST Post-Quantum Cryptography (PQC) standardization process. It relies on the hardness of decoding problems in error-correcting codes and is designed to remain secure against quantum attacks.

The goal of this project is not to implement the full algorithm, but to adapt and analyze critical subroutines on constrained hardware.

---

## Objectives

- Understand the structure and principles of the CROSS signature scheme
- Implement selected subroutines in C
- Port the implementation to an embedded platform (STM32F4)
- Validate correctness against reference implementations
- Perform side-channel analysis (SCA)
- Evaluate runtime and memory consumption

---

## Hardware Platform

- Riscure Pinata Board  
- Microcontroller: STM32F4
